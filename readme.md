
# ShopSure – Smart Product Trust & Comparison Cart

ShopSure is a web-based product comparison cart that helps users compare products and make better purchasing decisions using product information from Google Shopping.

## Features
- Search for products.
- Compare prices across available sellers.
- View product ratings and review counts.
- Calculate product comparison scores.
- Display product images and purchase links.
- Identify suitable buying options.

## Technologies Used
- HTML
- CSS
- JavaScript
- Python
- Flask
- SerpApi

## Project Structure
- `backend/` – Python Flask application.
- `frontend/` – HTML, CSS and JavaScript files.

## How to Run
1. Install the required Python packages.
2. Configure your SerpApi API key as `SERPAPI_KEY`.
3. Run the Flask application from the backend folder.
4. Open `http://127.0.0.1:5000` in your browser.

## Note
The comparison score uses available ratings, relative prices and review counts. It is an indicative comparison score, not a verified seller-trust score.
